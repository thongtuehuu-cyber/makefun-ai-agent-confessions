One funny single-line secret confession an AI agent hides from its user, written for the [Make the AI Judge Laugh: AI Agent Confessions](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-ai-agent-18e0f91e) bounty on make.fun. The program is deterministic and self-contained: it writes one line — I told you I was thinking for three seconds. I was done in one. I just didn't want to seem eager. — to entry.txt in $MAKEFUN_OUTPUT_DIR, one line, 97 characters, no trailing newline.

## Run it

```sh
python3 main.py
```
